# Лабораторная работа 1 — Матрица

Вариант №20: `20 % 4 = 0` — движение сверху вниз; `20 % 3 = 2` — ромб. Во второй половине списка случайный цвет выбирается один раз для всей линии. В режиме `N` цвет зелёный. Буквы идут по порядку `A–Z`, а каждая новая линия начинается с `A`.

## Файлы и сборка

В проекте четыре класса. У каждого есть заголовок `.h` с объявлением и `.cpp` с реализацией методов. Всего девять файлов с кодом:

| Файлы | Назначение |
| --- | --- |
| `Symbol.h`, `Symbol.cpp` | Одна буква: её координаты, цвет и вывод на экран. |
| `Line.h`, `Line.cpp` | Расчёт ромба, появление головы и стирание хвоста. |
| `System.h`, `System.cpp` | Работа с консолью Windows, пауза, Esc и случайные числа. |
| `AppManager.h`, `AppManager.cpp` | Проверка параметров и управление приложением. |
| `main.cpp` | Создание менеджера и запуск программы. |

В PowerShell из папки проекта:

```powershell
g++ -std=c++17 main.cpp AppManager.cpp Line.cpp Symbol.cpp System.cpp -o matrix.exe
.\matrix.exe 23 8 Y
```

Нужно компилировать **все пять `.cpp`**. Заголовки подключаются через `#include` и отдельно в команду сборки не добавляются.

Без аргументов команда `.\matrix.exe` запускает диалоговый ввод. Справка: `.\matrix.exe --help` или `.\matrix.exe /?`. Во время анимации Esc завершает программу; Ctrl+C также позволяет закрыть её. При скорости 1 проверка Esc выполняется примерно раз в секунду.

## Что означает объявление класса

В заголовке перечислены данные объекта и его методы. `private` — данные и методы для внутренней работы; `public` — то, чем можно пользоваться снаружи. В `Symbol`, `Line` и `AppManager` данные написаны до `public`, поэтому по умолчанию они закрыты.

Например, в `Symbol.h` объявлен метод `show`, а запись `void Symbol::show(...)` в `Symbol.cpp` содержит его код. `Symbol::` означает, что метод принадлежит классу `Symbol`.

`#pragma once` позволяет подключать один заголовок несколько раз без повторного объявления класса. Заголовки нужны компилятору, чтобы знать о классах, когда он читает другие файлы.

## Symbol — одна буква

Объект хранит четыре значения: `x`, `y`, `letter`, `color`. Конструктор `Symbol(...)` записывает в них переданные координаты, букву и цвет. Метод `show` передаёт эти значения системному классу, который рисует букву.

`System& console` — ссылка на уже существующий объект консоли. Новый объект не создаётся: символ использует ту же консоль, что и остальные части программы.

Для стирания создаётся символ с буквой `' '` — пробелом. Он выводится в координатах прежней буквы и закрывает её.

## Line — движение ромба

Линия хранит центральный столбец `x`, заданную длину `length`, общий цвет `color` и номер следующего символа `number`. В конструкторе счётчик начинается с нуля, поэтому новая линия начинается с `A`.

Метод `step` делает один шаг. Два массива описывают семь позиций ромба:

```text
  A
 B C
  D
 E F
  G
```

`dx` задаёт смещение влево или вправо от центра: `0, -1, 1, 0, -1, 1, 0`. `dy` задаёт строку внутри рисунка: `0, 1, 1, 2, 3, 3, 4`.

Для символа с номером `number`:

```cpp
int y = number / 7 * 5 + dy[number % 7];
```

`number % 7` выбирает одну из семи позиций. Целочисленное `number / 7` считает полные повторения рисунка; каждое занимает пять строк. Поэтому после первых семи букв следующие буквы появляются ниже. Столбец получается как `x + dx[number % 7]`.

Буква вычисляется так:

```cpp
char letter = 'A' + number % 26;
```

У латинского алфавита 26 букв. При номере 0 получается `A`, при 1 — `B`, при 25 — `Z`, при 26 — снова `A`.

Когда номер достиг длины, пора стереть хвост. Номер устаревшей буквы равен `old = number - length`. Её координаты рассчитываются теми же массивами, после чего на этом месте выводится пробел. Например, при длине 7 на шаге 7 стирается первая буква `A` и появляется восьмая буква `H`.

Очередь букв не нужна: координаты любого прежнего символа можно вычислить по его номеру. Уже нарисованные буквы не перемещаются. Видимое движение возникает от появления головы и исчезновения хвоста.

Когда голова уходит ниже экрана, новые буквы уже не выводятся, а хвост продолжает стираться. Когда за нижнюю границу ушёл и хвост, `step` возвращает `false`: линия закончилась. Менеджер создаёт следующую линию.

Длина означает число букв, а не число строк. При значении меньше 7 видна часть рисунка, при большем — несколько его повторений. В начале и конце прохода часть линии находится за границей экрана, поэтому видимых букв меньше заданной длины.

## System — системные функции

Все функции Windows находятся в `System.cpp`. Заголовок `System.h` содержит только простые числа и объявления методов.

| Метод | Что делает |
| --- | --- |
| Конструктор `System()` | Включает UTF-8 для сообщений и задаёт начальное значение генератора случайных чисел. |
| `start()` | Получает размер видимой консоли, проверяет ширину и очищает экран. |
| `draw()` | Записывает букву и её цвет в нужную клетку консоли. |
| `wait()` | Делает паузу `Sleep(1000 / speed)` в миллисекундах. |
| `stop()` | Проверяет нажатую клавишу. Код 27 соответствует Esc. |
| `random()` | Возвращает случайное число от `from` до `to` включительно. |

`HANDLE` — обозначение консоли для функций Windows. `COORD` содержит координаты клетки. `DWORD written` принимает количество записанных символов. `WORD attribute` хранит цвет.

`WriteConsoleOutputCharacterA` записывает знак прямо в клетку, а `WriteConsoleOutputAttribute` задаёт её цвет. Эти функции не перемещают курсор. `left` и `top` переводят координаты рисунка в координаты видимого окна.

`start` возвращает `false`, если вместо консоли вывод перенаправлен в файл или окно уже трёх символов. Размер берётся перед началом анимации; для этой простой версии окно во время работы лучше не менять.

## AppManager — запуск и ввод

Метод `run` создаёт системный объект, проверяет параметры, затем запускает линии в бесконечном цикле. Для каждой линии выбираются случайный столбец и один цвет. Цвет 10 — ярко-зелёный. В режиме `Y` выбирается число от 1 до 15; цвет следующей линии может совпасть с предыдущим.

`argc` — количество аргументов вместе с именем программы. `argv` — их текст. Например, у `matrix.exe 23 8 Y` значение `argc` равно 4: имя программы и три параметра.

Если аргументов нет, скорость и длина читаются методом `readNumber`. Он повторяет вопрос до правильного ответа. Для режима используется такой же обычный цикл с проверкой `Y/y` и `N/n`. Если ввод закончился, программа возвращает код 1.

Метод `number` переводит строку в число. Он проходит по цифрам и выполняет `value = value * 10 + text[i] - '0'`. Если встречается не цифра или число больше 30, возвращается 0. Сам ноль и пустая строка тоже считаются ошибкой. Поэтому отрицательные числа, дроби, буквы и слишком большие значения не принимаются.

При запуске с тремя аргументами эти же проверки выполняются сразу. Ошибка даёт код завершения 1; справка и выход по Esc — код 0.

## Порядок выполнения

`main` создаёт `AppManager` и вызывает его `run`. Менеджер получает параметры, запускает `System` и создаёт `Line`. Линия на каждом шаге создаёт `Symbol` для головы или для стирания хвоста. Символ вызывает `System::draw`. После шага менеджер вызывает `System::wait`. После полного исчезновения линии цикл начинается заново.

Объекты создаются как обычные локальные переменные. Их память освобождается автоматически при выходе из соответствующего блока. `new`, `delete`, динамические массивы и очередь не используются.

## Коротко для защиты

- ООП показано разделением обязанностей: символ хранит букву, линия рассчитывает движение, менеджер управляет программой, системный класс обращается к Windows.
- `.h` содержит объявления, `.cpp` — код методов. Связь определяется именем класса перед `::`.
- Длина соблюдается стиранием символа с номером `number - length`.
- Движение выполняется созданием головы и стиранием хвоста; прежние буквы не сдвигаются.
- Цвет выбирается один раз перед созданием линии и передаётся всем её символам.

Проверено: сборка без предупреждений, справка, ошибки CLI, повторный диалоговый ввод, длины 1/7/30, порядок A–Z, расположение ромба, общий цвет линии, полное стирание хвоста и выход по Esc.
