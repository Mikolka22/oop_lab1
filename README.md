# Лабораторная работа №1 «Матрица» — вариант №20

Это краткое объяснение программы из `main.cpp`

## запуск

```powershell
g++ -std=c++17 -Wall -Wextra -Wpedantic -O2 main.cpp -o matrix.exe
.\matrix.exe 23 8 Y
```

Скорость `23` означает примерно 23 новых символа в секунду; длина `8` означает максимум 8 одновременно видимых букв. Без аргументов программа последовательно спрашивает три значения. `--help` и `/?` выводят справку. Для выхода нажмите Esc или Ctrl+C. Анимации нужна обычная консоль Windows.

## Три класса

| Класс | Что хранит и делает |
| --- | --- |
| `Symbol` | Хранит позицию, букву и цвет одного символа. Метод `show` рисует букву или стирает её пробелом, после чего возвращает обычный цвет текста. |
| `Line` | Хранит буквы в `std::queue<Symbol>`, вычисляет форму ромба и выполняет один шаг движения методом `step`. Метод `finished` сообщает, что линия полностью ушла вниз. |
| `AppManager` | Хранит скорость, длину и режим цвета. Метод `run` очищает консоль, выбирает место и цвет каждой новой линии и задаёт паузу между буквами. |


## Откуда берутся буквы и ромб

Каждая новая линия начинает алфавит с `A`. Далее идут `B`, `C`, …, `Z`, после `Z` снова `A`. Случайных знаков в линии больше нет. Формула `L'A' + next_ % 26` выбирает очередную букву по номеру шага `next_`. Буква хранится как `wchar_t` и выводится функцией Windows `WriteConsoleW`.

Семь букв занимают пять строк:

```text
  A
 B C
  D
 E F
  G
```

Два массива в `Line::step` задают смещения относительно центрального столбца: по горизонтали `0, -1, +1, 0, -1, +1, 0`, по вертикали `0, 1, 1, 2, 3, 3, 4`. Для следующих семи букв рисунок повторяется на пять строк ниже. Случайный центральный столбец выбирается хотя бы в одном символе от края, поэтому боковые буквы остаются на экране.

Длина — это **число букв**, а не высота ромба. Если длина меньше семи, видна часть рисунка; если больше семи, видны соседние повторения рисунка.

## Как происходит движение

Каждый шаг `Line::step` создаёт следующую букву в нужной позиции. Она добавляется в конец `std::queue`. Если букв в очереди стало больше заданной длины, первая буква стирается пробелом и удаляется из очереди. Уже нарисованные буквы по экрану не передвигаются: линия «ползёт» за счёт появления головы и исчезновения хвоста.

Когда новая позиция оказывается ниже экрана, новые буквы уже не рисуются, а оставшийся хвост стирается по одной букве за шаг. После опустошения очереди `AppManager` начинает новую линию с буквы `A` в другом случайном столбце. Случайный цвет в режиме `Y` также выбирается при создании этой новой линии; все её буквы получают один цвет.

Пауза после каждого шага задаётся Windows-функцией `Sleep(1000 / speed)` в миллисекундах. `std::rand()` выбирает только столбец и цвет, а `std::srand(GetTickCount())` меняет последовательность случайных чисел при каждом запуске. `std::queue` сам управляет своей памятью; в программе нет `new` и `delete`.

## Ввод и ошибки

`main` сначала проверяет `--help` или `/?`. Если аргументов нет, он спрашивает параметры и повторяет запрос неверного ответа. При трёх аргументах проверяет их сразу; при другом количестве сообщает об ошибке.

Небольшая проверка `number` внутри `main` проходит по всем знакам строки: разрешены только цифры, а результат должен быть от `1` до `30`. Режимом могут быть только `Y/y` и `N/n`. При ошибке запуска возвращается код `1`, при успешном завершении — `0`.
